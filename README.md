## 🌟 مميزات النظام (Features)

نظام **VIENGO** ليس مجرد بوت عادي، بل هو نظام متكامل مصمم للسرعة والأمان:

- 🛡️ **نظام حماية متطور (Anti-Spam & Anti-Crash):** لا يمكن إيقاف البوت أو عمل سبام عليه.
- ⚡ **سرعة استجابة خيالية:** يعتمد على قاعدة بيانات UltraDB للرد في أجزاء من الثانية.
- 👥 **إدارة المجموعات الشاملة (Group Management):** ترحيب، مغادرة، ترقية، طرد، وحماية الروابط.
- 📥 **تحميل الوسائط:** يدعم التحميل من جميع المنصات بأعلى جودة.
- 🤖 **نظام الذكاء الاصطناعي (AI Integration):** مدمج بأحدث نماذج الذكاء الاصطناعي للرد والمساعدة.
- 🧩 **البوتات الفرعية (SubBots):** إمكانية تشغيل بوتات فرعية من داخل البوت الأساسي.
- 🎨 **تصميم ملكي للرسائل (Premium UI):** ردود البوت مصممة بإطارات وفخامة تميزه عن أي بوت آخر.

## 🚀 طريقة التثبيت (Installation)

### التثبيت عبر منصة Termux (لأجهزة الأندرويد)

قم بنسخ الأوامر التالية بالترتيب ولصقها في تطبيق Termux:

```bash
# 1. إعطاء صلاحيات التخزين
termux-setup-storage

# 2. تحديث الحزم الأساسية
pkg update -y && pkg upgrade -y

# 3. تثبيت لغة Node.js و Git
pkg install git nodejs -y

# 4. نسخ ملفات البوت (تأكد من رفع ملفاتك على الجيت هاب الخاص بك)
git clone [رابط-مستودع-جيت-هاب-الخاص-بك]

# 5. الدخول لمجلد البوت
cd [اسم-مجلد-البوت]

# 6. تثبيت المكاتب المطلوبة
npm install

# 7. تشغيل البوت
npm start
```
> 📌 **ملاحظة:** عند التشغيل لأول مرة، سيظهر لك كود (Pairing Code)، قم بإدخاله في إعدادات "الأجهزة المرتبطة" في الواتساب الخاص بك.

## 🌐 الاستضافة (Hosting)

لضمان عمل البوت 24 ساعة بدون توقف، ننصح باستخدام استضافات قوية مثل:

- **Heroku**
- **Render**
- **Railway**
- **VPS (Ubuntu/Debian)**

لتشغيل البوت على خوادم VPS (Ubuntu)، استخدم هذه الأوامر:
```bash
sudo apt update && sudo apt upgrade -y
sudo apt install nodejs npm git -y
# قم بنسخ المشروع وتشغيله باستخدام أداة pm2 ليعمل في الخلفية
npm install -g pm2
pm2 start index.js --name "VIENGO_BOT"
```
